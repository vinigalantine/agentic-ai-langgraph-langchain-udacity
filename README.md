# Udacity - AI Agents with LangChain and LangGraph

Already worked a bit with both technologies, just getting more into it.

Python version: 3.12.4

Right now using `venv`. (if you don't know what it is, don't ask me... jk here: [What is venv?](https://docs.python.org/3/library/venv.html))

### Set up your `venv`:

```shell
python -m venv .venv
```

### To use the `venv`:

Cmd
```bat
.venv\Scripts\activate.bat
```

Powershell
```shell
.\.venv\Scripts\Activate.ps1
```

### If it's a brand new `venv` or changes to `requirements.txt` were made

(Inside your venv (after the activate))
```shell
pip install -r requirements.txt
```
